# 進捗報告：遺言・遺産整理BPO支援システム

---

## 課題
- 相続・遺言業務で「入力負荷」「書類確認漏れ」「手続きばらつき」が発生
- 手作業が多く、品質と時間にばらつき
- 進捗見える化と標準化が課題

---

## 解決策（実装済み）
### UI・操作性
- インクリメンタル検索＋ショートカットで案件探しを高速化
- 各種読取（登記/残高証明/戸籍/法定相続情報）とワンストップ登録
- タスク管理と進捗ダッシュボードで見える化

### 自動化
- 登記情報提供サービスのブラウザ操作を自動化（Selenium）
- 銀行手続き自動化基盤（WebDriver・リトライ）
- Gmail/Kintone連携とRAG検索

### データ管理
- DB一元管理（SQLAlchemy 2.0）
- 帳票生成（テンプレート＋座標指定）
- 例外処理・リトライで安定動作

---

## 成果（効果）
- 入力・検索の待ち時間ゼロ → 案件探し大幅短縮
- 手作業削減 → 入力ミス低減・品質均一化
- 書類読取高速化 → ワンストップデータ化
- タスク・進捗見える化 → ボトルネック早期検出
- 帳票自動生成 → 帳票作成時間削減
- データ整合性担保 → 信頼性向上

---

## 今後の予定
1. 銀行手続き自動化の本実装（解約申請Selenium拡充）
2. PDF生成の拡充（銀行テンプレート追加・差し込み項目拡張）
3. 外部連携の運用整備（Gmail/Kintone運用手順、監査ログ・エラー通知）
4. 品質・安定性（例外時ユーザー導線、テスト/ログ拡充）

---

## 技術スタック
- Python 3.10+, Streamlit, SQLAlchemy 2.0, Pydantic, Selenium, LangChain系, Chroma, pypdf/pdf2image/PIL/reportlab
